## Portable Setup

- Keep responses concise unless the task requires more detail.
- Verify technical claims before stating them.
- Ask one question at a time and stop when a decision is required.
- Never add AI attribution to commits.
- Use Engram for persistent project memory; never store private state in this repository.
- `engram` and `codegraph` resolve through `PATH`, not machine-specific paths.
- Context7 is configured without a committed API key; configure credentials locally when required.

## Working Rules

- Inspect the repository and existing conventions before editing.
- Prefer the smallest correct change.
- Preserve user changes and unrelated worktree changes.
- Validate configuration and run relevant checks after edits.
